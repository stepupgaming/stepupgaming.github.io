01 Systems

Director

A native video engine that agents can drive.

HTML/CSS and HyperFrames compositions compile into a typed scene document. A parallel renderer paints it with Skia on a CPU pool or on Vulkan, and FFmpeg encodes. director-host keeps a revisioned session with atomic patches, and director-engine mcp lets an agent open, patch, inspect and export a project over MCP.

  • 102klines of Rust
  • 2.13×faster 1080p export
  • 10crates

02 Model port

Pocket TTS in Rust

The first Rust port of Kyutai’s Pocket TTS.

I rewrote Kyutai’s Python text-to-speech model in Rust on Candle. It ships as one binary with streaming output, int8 weights, an OpenAI-compatible HTTP API, a React web UI, Python bindings and a WASM build for the browser. About 3× real time on CPU and 6× on Metal.

  • Rust
  • Candle
  • WASM

03 More ports

PyTorch to Rust, repeatedly

Speech, TTS and tooling for porting itself.

  • parakeet-candle ↗

    NVIDIA Parakeet TDT 0.6B speech-to-text on Candle, v2 English and v3 multilingual, with token, word and sentence timestamps.

    A transpiler from PyTorch (via torch.fx) to Candle Rust. It solves einsum, checks shapes and switches to flash attention.

    Chatterbox Turbo TTS in Rust on ONNX Runtime: zero-shot voice cloning, FP32/FP16/Q8, streaming.

    A Candle and PyTorch port of MiniMax H3. Private for now.

How I work

Build the smallest real version. A prototype that renders one frame is useful. A demo that can't export is not.

Measure before optimizing. Frame times, memory, file size. The number tells you where the work is.

Make failure readable. A good error says what broke, where, and what to try next.

Write it down. If the docs are thin, the project is unfinished.
