Projects · Step Up Gaming, 2021 – present

Director · native video engine that agents can drive

github.com/stepupgaming/director
  • Compiles HTML/CSS and HyperFrames compositions into a typed, patchable scene document; a parallel Skia renderer paints it on a CPU pool or Vulkan and FFmpeg encodes. 102k lines of Rust across 10 crates.
  • 2.13× faster 1080p export; supports 3D transforms with depth sorting, backdrop blur, masks, blend modes, text and audio mixing.
  • Built an MCP server and revisioned host session: agents open, patch, inspect and export projects at about 11 ms per patch and 160 ms per 1080p frame on CPU.

Pocket TTS in Rust · first Rust port of Kyutai's Pocket TTS

128 stars · 29 forks
  • Rewrote the Python model in Rust on Candle: one binary, streaming output (RTF 0.33), int8 weights, an OpenAI-compatible HTTP API, a React web UI, Python bindings and a WASM build. About 3× real time on CPU, 6× on Metal.
